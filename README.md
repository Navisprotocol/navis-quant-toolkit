### 🛠️ About Navis Quant Toolkit
The **Navis Quant Toolkit** is an open-source suite of utility tools, microstructure data parsers, and data ingestion helpers provided by Navis Protocol for developers, quants, and traders in the Web3 space.

### 📦 Toolkit Modules
* **`data-parsers/`** - High-performance tools for parsing raw order book snapshots and tick-level microstructure data.
* **`macro-helpers/`** - Data ingestion utilities for normalizing multi-source inflation and economic metrics.
* **`onchain-signals/`** - Lightweight SDK helpers for monitoring real-time flow signals.

# Clone the repository
git clone [https://github.com/Navisprotocol/navis-quant-toolkit.git](https://github.com/Navisprotocol/navis-quant-toolkit.git)

# Install dependencies
